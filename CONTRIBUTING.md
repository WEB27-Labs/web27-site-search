# Contributing / Участие в разработке

Use a local/private development copy. Preserve the plugin slug, storage identifiers and public API. Translate user-facing strings with the literal `web27-site-search` domain, preserving placeholders. Include translator context where required. Run `python3 scripts/check.py` and browser tests, then verify in staging WordPress. Changes to connectors must enforce anonymous visibility, read-only access and bounded queries. Describe changes, actual tests and limitations in the pull request. Never commit API keys, production dumps, private content or logs. Submit only code and assets you have distribution rights for. Report vulnerabilities via [SECURITY.md](SECURITY.md), not public issues.

Работайте в локальной/закрытой копии. Сохраняйте slug, идентификаторы хранилища и публичный API. Переводите пользовательские строки через домен `web27-site-search`, сохраняйте плейсхолдеры и обязательные пояснения переводчикам. Выполните `python3 scripts/check.py`, браузерные тесты и проверку на тестовом WordPress. Адаптеры обязаны проверять публичность для анонимного пользователя, не изменять данные и ограничивать выборки. В PR указывайте изменения, фактические тесты и ограничения. Не коммитьте ключи, боевые дампы, закрытый контент и логи. Передавайте только материалы, которыми вправе распоряжаться. Уязвимости — по [SECURITY.md](SECURITY.md), не в публичные issues.
