# Changelog

## 1.0.0 — Initial public edition (release candidate)

- Local search for public WordPress content and optional virtual-page indexing.
- Optional conversational AI, RAG, background embeddings and conversation memory.
- OpenAI, OpenRouter, ProxyAPI and compatible custom endpoints.
- Opt-in public custom post types, taxonomies and catalog connectors.
- English and Russian interface and integrated setup guide.
- Design Studio, responsive launcher, four window modes and citation-linked material cards.
- Administrative access controls, request validation, privacy guidance and explicit uninstall cleanup.

Publication is pending final compatibility and directory checks.
