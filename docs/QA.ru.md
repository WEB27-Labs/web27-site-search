## Ограничения

- Наличие ссылок в ответе не доказывает точность фактов или полноту рекомендаций. Подходящий объект без ссылки может не получить карточку.
- Текстовый поиск лексический. Межъязыковая релевантность требует подходящей модели эмбеддингов и живой проверки.
- Обзор и векторы дополнительных источников ограничены (150 объектов на источник, 600 всего, 12 источников); только поддерживаемые адаптеры выполняют целевой поиск за пределами выборки. Отдельный HTML-индекс виртуальных страниц текстовый. Специализированные каталоги и закрытый контент требуют адаптеров с проверкой доступа.
- Опциональный виртуальный индекс проверяет до трёх URL того же сайта анонимно при запросе, до двух секунд на URL. Скорость зависит от хоста и кэширования.
- Лимит чата не включает эмбеддинги. Смена провайдера или модели может потребовать новых векторов.


## Проверка

Для автономных тестов выполните `python3 scripts/check.py --browser`. Официальные Plugin Check и WPCS доступны в GitHub Actions. Официальные проверки каталога, совместимость с живым WordPress и работа с реальными API ещё требуют подтверждения.
