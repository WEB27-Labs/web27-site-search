**Интеллектуальный поиск. AI-консультант. Ваш сайт WordPress.**

WEB27 Site Search — бесплатный поисковый плагин с открытым исходным кодом для WordPress, разработанный WEB27 Labs.

Объединяет локальный поиск, диалоговый искусственный интеллект, семантические эмбеддинги, RAG, универсальные источники знаний и настраиваемый поисковый виджет.

Локальный поиск работает без подключения внешних AI-сервисов.

## Скачать и установить

**[Скачать WEB27 Site Search — готовый установочный ZIP](https://github.com/WEB27-Labs/web27-site-search/raw/main/web27-site-search.zip)**

1. Скачайте ZIP-архив плагина.
2. Откройте панель управления WordPress.
3. Перейдите в раздел «Плагины → Добавить плагин → Загрузить плагин».
4. Загрузите архив, установите и активируйте плагин.
5. Откройте «Умный поиск → Инструкция по настройке».

Регистрация на GitHub и самостоятельная сборка не требуются.

**Используйте установочный ZIP по ссылке выше, а не автоматически сформированный архив исходного кода GitHub.**

Версия 1.0.0 — публичный кандидат в релиз. Официальные проверки WordPress.org и полная проверка совместимости продолжаются.

- Закреплённые корректировки и оценки ответов.

- Поддержка публичных пользовательских типов записей и таксономий.
- Подключение кастомных каталогов через API адаптеров.
- Русский и английский интерфейсы.
- Адаптивный поисковый виджет для компьютеров и смартфонов.

## AI-провайдеры

| Провайдер | AI-консультант | Эмбеддинги |
| --- | --- | --- |
| OpenAI | Поддерживается | Поддерживаются |
| OpenRouter | Поддерживается | Поддерживаются |
| ProxyAPI | Поддерживается | Поддерживаются |
| Custom API | Совместимые API | Совместимые API |

Для каждого провайдера предусмотрены отдельные настройки, выбор моделей и независимые тесты подключения.

AI-консультант и эмбеддинги включаются по желанию администратора.

Автоматическое переключение между платными сервисами не выполняется.

## Универсальные источники знаний

WEB27 Site Search может получать публичные сведения не только из стандартных записей и страниц WordPress.

| Источник | Поддержка |
| --- | --- |
| Опубликованные записи и страницы | По умолчанию |
| Публичные виртуальные страницы | Дополнительная индексация sitemap и HTML того же сайта |
| Пользовательские типы записей | После включения администратором |
| Публичные таксономии | После включения администратором |
| Кастомные каталоги | Через API адаптеров |
| Закрытые данные и исходники плагинов | Автоматически не индексируются |

Встроенный адаптер MAX Games Core позволяет подключать публичный игровой каталог. Наличие игрового ядра не является обязательным условием работы плагина.

Разработчики могут подключать собственные каталоги через [API адаптеров](docs/CONNECTORS.md).

## Начало работы

После активации плагина:

1. Откройте «Умный поиск → Инструкция по настройке».
2. Проверьте локальный поиск без подключения AI.
3. Дождитесь выполнения фоновой индексации.
4. При необходимости подключите дополнительные публичные источники знаний.
5. Настройте внешний вид в разделе «Интерфейс → Конструктор дизайна».
6. Для подключения AI выберите провайдера и укажите собственный разрешённый API-ключ.
7. Проверьте работу AI-ответов и эмбеддингов отдельно перед включением семантического поиска.

Используйте плавающую кнопку или шорткод:

`[web27_site_search]`

## Системные требования

- WordPress 6.6 или новее.
- PHP 8.1 или новее.
- Расширение PHP mbstring.
- SimpleXML и DOM для дополнительной индексации sitemap и HTML.
- Аккаунт внешнего API только при использовании соответствующих AI-функций.

Указаны заявленные минимальные требования. Полная проверка совместимости продолжается.

## Конфиденциальность и расходы

Локальный поиск не требует API-ключа.

При подключении внешних AI-сервисов выбранному провайдеру могут передаваться запросы посетителей, публичные фрагменты содержимого сайта, инструкции администратора и контекст разговора.

Для формирования эмбеддингов могут передаваться публичные текстовые фрагменты.

Внешние провайдеры могут взимать плату за использование API. Суточный лимит AI-ответов не ограничивает расходы на эмбеддинги.

API-ключи хранятся на стороне сервера. Администратору рекомендуется изучить условия провайдера, настроить ограничения расходов и указать используемые сервисы в политике конфиденциальности сайта.

Память диалога можно отключить. Дополнительный журнал запросов по умолчанию выключен.

Подробнее: [Конфиденциальность и внешние сервисы](readme.txt).

## Известные ограничения

Обзор и векторная индексация дополнительных источников ограничены 150 объектами на источник, 600 объектами суммарно и 12 источниками.

Поддерживаемые адаптеры могут выполнять дополнительный текстовый поиск за пределами этой выборки.

Полное семантическое покрытие больших каталогов, отдельного HTML-индекса виртуальных страниц, межъязыковая релевантность и фактическая точность AI-ответов не гарантируются.

Специализированные структуры данных и правила доступа могут требовать дополнительных интеграций.

Подробнее: [Ограничения и контроль качества](docs/QA.ru.md).

## Сборка из исходного кода

Полный исходный код доступен в этом репозитории.

Сборка установочного архива:

    python3 scripts/build.py /tmp/web27-site-search.zip

Запуск автоматических проверок:

    python3 -m pip install -r tests/requirements.txt
    python3 scripts/check.py

Браузерное тестирование:

    python3 -m playwright install chromium
    python3 scripts/check.py --browser

Автономные тесты не требуют внешних API-ключей или платных запросов и не заменяют проверку на действующем WordPress.
