# Security policy / Политика безопасности

## English

Current review candidate: 1.0.0. No production support or public release is implied by this package. Earlier candidates are superseded for review.

After the official repository becomes public and private vulnerability reporting is enabled, use Security → Report a vulnerability. Until then, request a verified private maintainer contact through https://web27.ru/ before transmitting sensitive details. The maintainer must confirm the private route before public release. Do not publish exploit details, API keys, database backups or private queries in issues. Provide the affected version, sanitized minimal reproduction and impact. No response-time or bounty commitment is made.

## Русский

Текущий кандидат для проверки — 1.0.0. Пакет не означает начало публичного сопровождения или релиз. Прежние кандидаты заменены для ревизии.

После публикации официального репозитория и включения private vulnerability reporting используйте Security → Report a vulnerability. До этого запросите проверенный конфиденциальный контакт через https://web27.ru/, прежде чем передавать чувствительные сведения. Владелец должен подтвердить рабочий закрытый канал перед публикацией. Не размещайте публично детали эксплуатации уязвимостей, ключи, дампы или приватные запросы. Укажите версию, обезличенное воспроизведение и последствия. Обязательства по сроку ответа или вознаграждению не заявлены.
