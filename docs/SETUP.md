# Setup and operation (EN)

[Русский](SETUP.ru.md)

The complete 14-section guide is embedded in the plugin and is accessible through the Site Search menu, guide tab, plugin-list shortcut and contextual settings links. No provider key is needed to read it.

1. **Start locally.** On staging, install the FULL archive. Keep the existing plugin directory if updating. Confirm Site Search is active and the public widget opens. In Index, enable the desired posts/pages, then check a published title. Allow WP-Cron to run; the normal text index is distinct from optional virtual indexing. Do not clear a working index merely to change language or appearance.
2. **Additional knowledge.** In Knowledge sources, review discovered public CPTs, taxonomies and connectors. Select only data that an anonymous visitor can access. Check the site profile and search a known object. Proprietary and access-controlled catalogs need a trusted adapter. See [connector API](CONNECTORS.md).
3. **Provider.** In AI and answers select OpenAI, OpenRouter, ProxyAPI or Custom API. Obtain a permitted account from the official provider: [OpenAI](https://platform.openai.com/api-keys), [OpenRouter](https://openrouter.ai/keys), [ProxyAPI](https://proxyapi.ru/). Enter the key server-side in settings; save, load models or enter the exact model ID. Test chat with the built-in synthetic request, then enable chat when ready. A listed model is not proof of access. A profile switch pauses chat and semantic search until explicitly enabled again. A custom endpoint must be compatible with the selected API protocol and use HTTPS.
4. **Embeddings.** Select a supported embedding model and run its separate test. Enable semantic search only after reviewing cost and data disclosure. Additional source embeddings are a further opt-in. The scheduler gradually processes new/changed text. Do not mix vector models. Changing provider/endpoint/model can require re-embedding. Daily chat quota is not an embedding quota. A failed background request is delayed for five minutes; resolve credentials, billing or network issues first.
5. **RAG and instructions.** Set the number of sources and context budget, answer style, data rules, dialogue style and any site-specific instructions. Use factual public material in the knowledge sources. Instructions apply to the next request; no reindex is needed. Test both direct and follow-up questions. Keep private or sensitive facts out of prompts.
6. **Language.** WordPress user profile controls administration language. Interface and behavior controls widget language (Automatic, English, Russian). Explicit label reset restores only default launcher, panel title and placeholder. AI answer language is determined separately; local excerpts stay in the original language.
7. **Design Studio.** In Interface choose light, dark, system, high contrast or custom colors. Configure desktop/mobile corner and offsets, launcher shape and label/icon, visibility, modal/right/left/full window, width, height, radius and material layout (grid, list, carousel, compact). Check live sample preview in both viewport modes, save and verify the actual theme. Theme integrations are respected by default. A missing or unsuitable cover uses a neutral icon. Only validated cited materials appear as cards in AI mode; local search shows retrieved materials.
8. **Privacy and diagnostics.** Review external-service details in [readme.txt](../readme.txt). Set provider spending limits, disable memory or journal if not needed, and test local fallback with the provider disabled. Record only sanitized error codes and reproduction steps. A 401/403 can indicate a credential or permission issue; a 429 can indicate a quota or rate limit; do not retry indefinitely. Never paste keys, complete conversations or private database exports in a public issue.

## Verification before production

Use [QA](QA.md) and [upgrade/rollback](UPGRADE-ROLLBACK.md). Verify public/private transitions and membership rules, actual database migration, cron, both languages, browser/mobile views, provider availability and cost. Official Plugin Check and compatibility results are still required for directory submission.

For the suggested site privacy notice, see WordPress Settings → Privacy. Adapt it to your actual providers, log retention and consent configuration. The read-only passage preview is local text only; the full query test can incur charges.
