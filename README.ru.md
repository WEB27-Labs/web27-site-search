# WEB27 Site Search

[English](README.md) · [Настройка](docs/SETUP.ru.md) · [Конфиденциальность и сервисы](readme.txt) · [История изменений](CHANGELOG.ru.md)

**Локальный поиск и опциональный AI-консультант на основе материалов сайта WordPress.**

WEB27 Site Search помогает посетителям находить публичные материалы, задавать уточняющие вопросы и переходить к подходящим страницам. Объединяет локальный поисковый индекс, опциональные семантические эмбеддинги, RAG и настраиваемый виджет поиска. Локальный режим не требует аккаунта внешнего AI.

**Статус:** 1.0.0 — первая публичная редакция, пока кандидат в релиз. Исходники и установочный пакет подготовлены для закрытой проверки и тестового WordPress. Реальная совместимость WordPress, официальные проверки каталога и работа живых API остаются условиями выпуска. Одобрение WordPress.org не заявлено.

## Возможности

- Локальный поиск по опубликованным записям и страницам без парольной защиты.
- Опциональная индексация виртуальных публичных страниц по sitemap того же сайта, фоновая индексация, фрагменты текста и эмбеддинги.
- Опциональный AI-диалог с опорой на найденные материалы, настраиваемые инструкции, контекст разговора, ссылки на источники, локальный резервный режим, закреплённые корректировки ответов, опциональный журнал и оценки.
- Подключаемые публичные CPT, таксономии и [API адаптеров](docs/CONNECTORS.md) для кастомных каталогов. Встроен адаптер MAX Games Core; ядро игр не является обязательной зависимостью.
- OpenAI, OpenRouter, два профиля ProxyAPI и произвольные совместимые HTTPS API. Раздельные настройки, каталог моделей, независимые тесты чата и эмбеддингов; нет автоматического переключения между платными сервисами.
- Английская и русская админка, встроенное руководство и виджет. Язык виджета выбирается независимо от локали сайта, язык ответа AI учитывает запрос и диалог.
- Пять цветовых схем, раздельное расположение кнопки для ПК и телефона, четыре режима окна, размеры, предпросмотр, шорткод и четыре формата карточек материалов.
- Карточки AI формируются по проверенным ссылкам из ответа; поддерживаются публичные обложки того же сайта. Выдуманные ссылки не нужны.

## Быстрый старт

1. Получите **установочный FULL ZIP** из согласованного релиза или соберите по инструкции ниже. Не устанавливайте автоматически сформированный архив исходников GitHub.
2. На тестовом WordPress откройте Плагины → Добавить новый → Загрузить плагин. Установите и активируйте. Каноническая папка — `web27-site-search/`.
3. Откройте **Умный поиск → Инструкция по настройке**. Проверьте поиск по заголовку опубликованной страницы без AI. Дождитесь выполнения фоновой индексации.
4. При необходимости подключите публичные источники в разделе **Источники знаний**, настройте **Интерфейс → Конструктор дизайна**. Используйте плавающую кнопку или шорткод `[web27_site_search]`.
5. Для AI выберите провайдера в **AI и ответы**, получите собственный разрешённый ключ, выберите модель и выполните тест чата. Эмбеддинги проверяйте отдельно перед включением семантического поиска. Обе платные функции включаются добровольно.

Заявленные минимальные требования: WordPress 6.6, PHP 8.1, расширение mbstring. Для дополнительной индексации sitemap/HTML нужны SimpleXML и DOM (DOM для полного извлечения HTML). Это заявленные требования, а не подтверждённая матрица совместимости. См. [настройку](docs/SETUP.ru.md) и [обновление](docs/UPGRADE-ROLLBACK.md).

## Какие данные поддерживаются?

| Источник | Поддержка |
| --- | --- |
| Опубликованные записи и страницы | По умолчанию |
| Виртуальные страницы того же сайта | Опциональный текстовый индекс sitemap/HTML |
| Публичные CPT и таксономии | После включения администратором |
| Кастомные каталоги | Явный публичный адаптер и поддерживаемый целевой поиск |
| Закрытые данные, произвольные таблицы, исходники плагинов | Автоматически не индексируются |

Обзор и векторы дополнительных источников ограничены 150 объектами на источник, 600 суммарно и 12 источниками. Поддерживаемые адаптеры могут выполнять дополнительный текстовый поиск за пределами выборки. Полное семантическое покрытие больших каталогов и отдельного HTML-индекса виртуальных страниц ограничено. Специальные метаданные магазинов, ограничения членства и проприетарные данные требуют отдельных интеграций. Локальный поиск текстовый; межъязыковая релевантность и достоверность AI не гарантированы. [Ограничения и QA](docs/QA.ru.md).

## Конфиденциальность и расходы

Чат и эмбеддинги включаются независимо. Внешний сервис может получать вопросы, публичные выдержки, инструкции администратора и историю разговора; при эмбеддингах также передаются публичные фрагменты. Возможна оплата запросов. Суточный лимит чата не включает расходы на эмбеддинги. Изучите условия провайдера, настройте лимиты у него и отразите подключённые сервисы в политике конфиденциальности сайта. Ключ для локального поиска не нужен. Ключи остаются на сервере; не включайте их и боевые дампы в репозиторий. Память диалога по умолчанию включена и отключается; журнал по умолчанию выключен. Подробности в [readme.txt](readme.txt).

## Сборка и тесты

```sh
python3 scripts/build.py /tmp/web27-site-search.zip
python3 -m pip install -r tests/requirements.txt
python3 scripts/check.py
```

Для браузерных тестов установите Chromium (или выполните `python3 -m playwright install chromium`), при необходимости задайте переменную `CHROMIUM` с путём к исполняемому файлу. Выполните `python3 scripts/check.py --browser`. Автономные тесты не требуют WordPress, API-аккаунта или платных вызовов. Они не подтверждают живую совместимость. См. [QA](docs/QA.ru.md) и [правила участия](CONTRIBUTING.md).
